# Ethical Hacking Practice Lab (HTML)

**Owner:** Akash Kumar (Master Creox), BCA Cybersecurity student
**Status:** Practice lab v1 — HTML, phone + laptop, no install, no server.
**Scope: PRACTICE ONLY, LAB ONLY.** This lab teaches ethical-hacking tools through guided simulations, quizzes and fictional lab cases. It does NOT hack real systems, accounts, WiFi networks or people, and it does NOT scan or attack anything from the browser.

## Open it
Open `index.html` in any browser (phone Chrome / laptop Chrome). No install, no account, no server needed.
Progress is saved in that browser's localStorage (per device — phone and laptop progress do not auto-sync in v1).

## What is inside
- **20 tools to master:** Nmap, Wireshark, Burp Suite, Metasploit, SQLmap, Hydra/John, Nikto, Netcat, Gobuster, FFUF, Hashcat, OWASP ZAP, Nuclei, Amass, Subfinder, Dirb, Aircrack-ng (own WiFi only), WPScan, Enum4linux, The Harvester.
- **Each tool:** Learn → Commands → Practice + Coach → Challenge → Mastered.
- **Simulator Terminal:** A SAFE simulated terminal (not a real terminal). Type lab commands, get simulated lab output, get coach correction on wrong/dangerous commands. It performs no real scanning, attacking or system change.
- **Case Solving:** 3 fictional lab cases — Lab Website Defaced (SQLi), Lab Phishing Email, Lab Server Brute Force. Read evidence, answer, coach corrects, mark Case Solved.
- **Cyber Forensics Lab:** Forensics tools (FTK Imager concept, Autopsy, Volatility, Sleuth Kit, strings+hash, Wireshark forensics use), core rules (never change original evidence, work on copy/image, hash integrity, chain of custody), practice questions, and a fictional Deleted File Recovery case.
- **Pro Path:** Beginner → Intermediate → Advanced → Pro. Pro = all 20 tools Mastered.

## Hard boundaries (never to be added)
- No exploitation of real-world targets, no payloads for real systems, no malware.
- No password cracking against real accounts, no credential theft, no brute-force against real logins.
- No scanning/testing/accessing any system, network or account without the owner's clear permission.
- No packet sniffing of other people's traffic.
- Practice targets are ONLY: Akash's own devices, his own lab VMs / test apps, and deliberately vulnerable lab apps with no real user data. An authorization gate in the lab enforces this before practice.

## Mistake-correction coach
When an answer/command is wrong, the coach explains WHAT was wrong, shows the CORRECT version, explains WHY, and lets the learner retry — until it is right.
