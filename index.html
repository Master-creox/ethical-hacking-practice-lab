🔍 Cyber Forensics Lab — Evidence se Sach Dhoondho

Ye sab FICTIONAL lab forensics scenarios hain — koi real case, real victim ya real data nahi hai. Forensics ka rule yaad rakho: original evidence ko kabhi change mat karo — hamesha copy/image par kaam karo, hash se integrity check karo, aur chain of custody likho.

📚 Forensics Tools — seekhne layak

  • FTK Imager (concept) — Disk ki forensically-sound image banana, bina original ko change kiye. Command concept: image banao, hash note karo.
  • Autopsy — Disk image ko analyse karna: deleted files, timeline, browser history (lab image par).
  • Volatility — Memory (RAM) forensics: lab memory dump se running processes, network connections dhoondhna.
  • Sleuth Kit (fls / icat) — File system se deleted files ki list aur recovery (lab image par).
  • strings + hash (sha256sum) — File me chhupe text dhoondhna, aur evidence ki integrity hash se verify karna.
  • Wireshark (forensics use) — Lab network capture se timeline banana: kab, kahan, kya hua.
